## 文档维护规则

- 功能行为发生变化时，同一提交必须更新 `features.md`。
- 新增或修改服务端接口时，同一提交必须更新 `api.md`。
- 修改存储键、数据版本或迁移方式时，同一提交必须更新 `data-storage.md`。
- 修改工作流、签名、商店轨道或密钥名称时，同一提交必须更新 `release.md`。
- 修改测试命令、Flutter/Python 版本或验收门槛时，同一提交必须更新 `testing.md`。
- 发布新版本时更新根目录 `CHANGELOG.md`，并核对 `frontend/pubspec.yaml`。
- 商店审核状态会变化，不写成长期事实；应提示读者到对应控制台确认。
- 文档正文使用中文。命令、文件路径、接口路径、代码类型和配置键保持源代码中的原名。
