## 闪卡 — 牌面识别训练

**玩法**：显示一张麻雀牌，从 4 个选项中选出正确答案。

**流程：**
1. 从首页点 🃏 Flashcards 进入
2. 牌面出现，倒计时 8 秒
3. 从 4 个选项中选择正确答案
4. 正确 → 绿色反馈 + 金色脉冲动画 + 扣 1 心
5. 错误 → 红色反馈 + 自动显示助记 + 进入错题池
6. 超时 → 视为错误，显示助记

**注意：**
- 错误和超时不扣心（进错题池免费重练）
- 每日挑战优先消耗（免费）
- 付费用户不扣心

## 何切 — 牌效率选择

**玩法**：一副手牌 + 一张自摸牌，从手牌中选出最佳弃牌。

**流程：**
1. 从首页点 ⚔️ Nani-Kiru 进入
2. 上方显示"摸到哪张牌"
3. 下方 14 张手牌可点击
4. 选中一张牌 → 点 Confirm 确认
5. 正解 → 金色斜切动画 + 粒子爆发
6. 错误 → 红色斜切 + 显示正确弃牌

**工具栏：**
- 💡 Hint — 提示"寻找顺子和刻子，丢弃孤张牌"
- 🏳️ Skip — 跳过（视为错误，消耗体力）

## 错题墓地

**入口**：首页 👻 Graveyard

- 显示所有答错的牌
- 按紧急程度排序（SRS errorWeight 降序）
- 点击任意错题进入复习模式（**不耗体力**）
- 复习模式与正常闪卡相同，答对后从墓地移除

---

## 每日挑战

- 每天前 **3 题不耗体力**
- 首页 ✨ DAILY CHALLENGE 卡片显示剩余次数
- 点击 ⚡ START CHALLENGE 直接进入何切
- 次日 0 点自动重置为 3/3

## 体力系统

| 动作 | 消耗 |
|------|:--:|
| 闪卡答对 | 1 ❤️ |
| 何切完成（正确/错误/跳过） | 1 ❤️ |
| 错题重练 | **0 ❤️** |
| 每日挑战前 3 题 | **0 ❤️** |

- 每天 10 心，次日 0 点重置
- 付费会员**无限心数**
- 心耗尽 → 弹出战绩窗口

## 其他页面

### Scanner — 役种参考
- 列出所有常见役种（立直、断幺九、混一色等）
- 每个役种的番数和基本牌型

### Collection — 役种收藏册
- 达成条件后解锁役种卡片
- 已解锁的役种显示牌型图

### Tile Browser — 全牌浏览
- 34 种麻雀牌完整列表
- 每种牌的助记描述和混淆牌提示

### Profile — 个人资料
- 段位和 ELO 评分
- 总学习次数统计

### Settings — 设置
- 音效开关
- 动画速度调整
- 关于（版本号）

## TestFlight 沙盒测试

1. iPhone 设置 → App Store → 翻到底 → Sandbox Account
2. 创建测试账号（随便填邮箱）
3. 打开 TileSlash → 正常使用
4. 购买时用沙盒账号登录 — **不扣真实费用**
5. 测试取消订阅：Settings → App Store → Sandbox Account → Manage
